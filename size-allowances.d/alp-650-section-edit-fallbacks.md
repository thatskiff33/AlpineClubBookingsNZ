# File-size allowances for ALP-650

The section-edit hook now requires `loadErrorFallback` and `saveErrorFallback`.
A failure that is not an `ApiRefusalError` shows that sentence, never the
browser's own words. Every growth below is those option lines, the constant that
names each sentence once, or an import of `ApiRefusalError` or its helpers, in a
file or function that was already over its budget.

file: src/app/(admin)/admin/system/backups/backups-client.tsx
lines: 815
reason: the plan (ALP-650) makes every useSectionEditState caller name its own
  fallback sentence, so a failure with no worded refusal shows that instead of
  "Failed to fetch"; the added lines are those options and the constant that
  names each sentence once, set beside the save they describe. Splitting this
  already-oversized component to absorb a handful of lines would invent a seam
  for this change alone.
