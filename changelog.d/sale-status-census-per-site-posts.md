- **The check that every booking confirmation and cancellation writes its member-money journal entry now checks each write, not each file.** The automated census used to pass as long as a file mentioned the journal-posting call somewhere, so a new or changed cancel path that skipped its entry could go unnoticed. It now requires the posting call in the same function as each status write, and names the file and line of any write that lacks it (#4928). No runtime behaviour changes.
