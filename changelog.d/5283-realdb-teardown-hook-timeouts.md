- **Database test suites no longer fail on a slow test machine after every check has passed (#5283).** Six real-PostgreSQL test suites delete their temporary databases and roles in a clean-up step that had only the test runner's 10-second default to finish, so on a busy machine the clean-up could time out and report a failure even though every check had passed. Each clean-up step now has the same explicit time allowance as its set-up step. Nothing about the application changed.
