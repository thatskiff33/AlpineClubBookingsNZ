- **A failing page no longer throws you out of the area you were in (#4467).** Every area — admin, the member pages, finance, the lodge kiosk, sign-in and the public website — now has its own error screen, shown inside that area's navigation instead of the site-wide one. **Try again** reloads just the failed page from the server, a link takes you back to the area's home page, and only an error ID is shown, never the technical message. Admin and lodge pages also show a loading placeholder while a page loads, and every loading placeholder now tells screen-reader users that the page is loading.
