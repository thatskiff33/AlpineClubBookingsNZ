- **Tests that scan the whole source tree no longer fail on a busy test machine (#5439).**
  A check that reads and searches every production file for hand-built date formatters took longer than the test runner's 5-second default on a loaded CI runner, so it failed with "Test timed out" although nothing was wrong. A new check fails any test file that reads the whole tree without one. No checks were loosened and no behaviour changes for clubs.
