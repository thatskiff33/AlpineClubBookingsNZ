- **The admin booking-request queue and the server now build a school party
  from one rule (#3486).** When an officer adjusts a school group's numbers
  before quoting, the rate boxes they fill in come from the same code the
  server uses to rebuild the guest list on save, instead of a second copy kept
  in step by hand. Nothing an officer sees or does changes; this removes the
  way the two could have drifted apart and priced a party the officer had no
  rate box for.
