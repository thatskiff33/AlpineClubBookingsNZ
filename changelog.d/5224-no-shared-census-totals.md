- **Two pull requests that each add an audit record or an admin button no longer conflict with each other (#5211).** The audit-writer and view-only button censuses used to publish exact totals in about a dozen files, so every such pull request edited the same lines. They now check each site instead of counting them: every audit write site has its own line in a generated ledger (`pnpm run audit:census --write`), recording the category it files under and how it writes, and every view-only button either opts out under a checked banner rule or sits in a reviewed list of controls that keep their own reason. The checks are as strict as before about an unclassified or unreviewed site, and stricter about an audit writer quietly changing category. No behaviour clubs see has changed.
