- **Setup wizards announce a failed action every time it happens (#4975).** In the **Stripe**, **Google** and **Xero** setup wizards, **Site style**, the lodge setup wizard, and the Alpine server lodge **Download**, a failed save, verify, upload, disconnect or download now moves keyboard focus to its error and is read out by screen readers. It does so again when the same failure repeats word for word, where before a repeat could pass silently. Errors found when a page loads, such as a failed connection-status read, still show without moving focus.
