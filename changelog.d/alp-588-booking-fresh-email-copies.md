- **Send a fresh copy of a booking email (ALP-588).** A booking's page now lets an officer with bookings edit access send a fresh booking confirmation, pre-arrival reminder or guest payment link. These emails carry a door code or payment link, so the club keeps no copy and a failed one is never retried. A fresh copy is built again from the booking as it is now and sent to its current owner, and the payment link is re-issued so the old one stops working. Only a copy that actually went out is reported as sent; it then archives that email's earlier failures and is recorded in the audit log. The Email Deliverability failure list links each such failure to its booking.
