- **Admin settings sections no longer show "Failed to fetch" when the connection drops.** Every settings card with an Edit button (booking policies, security, maintenance, backups, lodge settings, member fields, privacy, analytics, video meetings and the rest) showed the browser's own words — "Failed to fetch", or "Load failed" in Safari — when loading or saving never got an answer, and a garbled parse error when the server answered with an error page. Each card now shows its own plain sentence, such as "Failed to load settings". Refusals the server explains read exactly as before.
