- **A read-only report finds refund credit notes that Xero has voided but the app still shows as live (#4336).** Before a recent fix (#4288), an older reading from Xero could bring back a refund credit note the club had already voided, and each one can hide a whole refund: for example, a $200 bank refund that the app counts as documented while Xero credits nothing. Those cases cannot be found from the app's own records, so the new report asks Xero about every refund credit note the app still treats as live and lists the ones Xero says are voided or deleted, with the payment, booking, note number and amount. It changes nothing in the app or in Xero.

  What you need to do: once #4288 is deployed, run `pnpm run xero:voided-refund-note-report` (add `--csv <file>` to keep a copy), then correct each listed refund by hand. If it says the list is incomplete, run it again.
