- **Edit credit notes now record which ledger money they return (ALP-753, #5253).**
  When a booking edit lowers the price, the credit note sent to Xero now records, in the export manifest, exactly which part of the stay charge it gives back, or why it cannot say (for example, when the note also nets a change fee). A second note for the same reduction is recorded as already covered rather than counted twice. A new test sends the booking invoice, an edit's credit note and a supplementary invoice through the app's own Xero code against the test Xero, reads each back, and checks the record covers exactly what Xero holds. Nothing sent to Xero changes.
