- **Booking Requests shows a count on every tab and opens where the work is (#4969).**
  All four tabs (Approvals, Changes, Policy Exceptions and Public Requests) now
  show how many items are waiting, and the four counts add up to the sidebar's
  Booking Requests badge. Opening the page from the sidebar, a bookmark or the
  dashboard card now lands on the first tab with work instead of always on
  Approvals, so following the badge never shows an empty list while the work
  sits on another tab. A link that names a tab still opens that tab. The
  dashboard card also appears when only policy exceptions or public requests
  are waiting. A policy-exception request to change a booking is counted on
  Policy Exceptions, where it is listed, rather than on Changes; the sidebar
  total is unchanged.
