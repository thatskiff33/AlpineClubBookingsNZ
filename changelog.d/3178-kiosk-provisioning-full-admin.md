- Setting up a lodge kiosk login now needs a Full Admin. Opening the kiosk page
  still shows what is there to anyone who can view lodge settings, but the first
  kiosk account is only created when a Full Admin opens it — previously any
  officer who could view the page brought the account into existence just by
  loading it, including the read-only admin role, which is described to clubs as
  being able to view without making changes. Nothing changes for a club that
  already has a kiosk, and a Full Admin setting one up sees no extra step.
