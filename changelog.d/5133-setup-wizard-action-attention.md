- **Setup wizards announce a failed action every time it happens (#4975).** In the **Stripe**, **Google** and **Xero** setup wizards, **Site style**, the lodge setup wizard, the lodge download that follows saving the Alpine server API key, and the Disconnect button on the **Xero Sync** page, a failed save, verify, upload, disconnect or download now moves keyboard focus to its error and is read out by screen readers. It does so again when the same failure repeats word for word, where before a repeat could pass silently. Errors found when a page loads, such as a failed connection-status read, still show without moving focus.

  Two things are unchanged. On the Alpine server page, the Save, Save key, Enable or Disable, Upload and Download buttons still show a failure without moving focus. In the lodge setup wizard, a season or chore copy where only some rows are refused still lists those rows in its summary.
