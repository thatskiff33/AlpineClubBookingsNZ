- **Webhook events interrupted by a server restart are now picked up again automatically (#4921).**
  A Xero event left **Processing** because its server stopped mid-run is now reset and processed again by the inbound worker once it has been stuck for 15 minutes. You no longer need to Replay it, though Replay still works at once for an event already past those 15 minutes. Its stuck operation is taken over too, and two workers racing for the same stuck event cannot both process it.
  Bounce and complaint notices from Amazon SES now follow the same rule as Stripe payments: a notice whose first attempt was cut off is processed when Amazon SNS sends it again more than 15 minutes later, instead of being dropped as a duplicate. SNS only retries that long if its delivery policy is set as `CONFIGURATION.md` describes; the default gives up within a minute. A repeated copy of the same bounce is no longer counted twice towards blocking an address.
