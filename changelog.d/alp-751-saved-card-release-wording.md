- **A failed saved-card charge no longer says the booking went back to pending when it did not (#5279).**
  When **Confirm pending guests** (or the saved-card charge an administrator runs) fails and the booking cannot be handed back straight away because the database is busy, the officer is now told the truth: the booking stays confirmed but unpaid for now, and the next scheduled pending-booking run returns it to pending automatically, within a few hours. The usual case, where the booking is handed back at once, keeps its existing wording. Nothing about charging, releasing or recovering the booking changed.
  If the card network is still processing the payment at that moment, the message instead says the booking stays confirmed until the payment finishes: paid if it succeeds, returned to pending by the next scheduled run if it fails.
