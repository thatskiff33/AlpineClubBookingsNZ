- **The member lodge roster now shows nights the whole lodge is privately
  booked** (#3474). In clubs that run the roster, nights under a whole-lodge
  hold appear on **Who's at the lodge** as one "Reserved for a private booking"
  row, without saying whose booking it is or how many people are on it. The
  booking calendar still shows those nights as full; before this change a
  member could tell a held night from a genuinely full one by comparing the
  calendar with the roster's head count, so the roster now says it outright,
  as it already does for custodians. Clubs that do not run the roster are
  unchanged. See [Who's at the lodge](../docs/user-guide/whos-at-the-lodge.md).
