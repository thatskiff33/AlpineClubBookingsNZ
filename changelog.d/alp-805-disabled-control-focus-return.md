- **Pressing a button that waits for the server no longer drops keyboard focus (ALP-805).**
  A browser moves focus off a button the moment it is disabled, and many member and public buttons are disabled while their request runs. When the button stayed on screen afterwards, focus was left on the page itself, so a keyboard or screen-reader user had to find their place again. Focus now goes back to the button on: acknowledging a notice, saving an arrival time, room request or guest dietary note, applying a promo code, downloading your data, signing off an induction, placing a food order, signing in with a password, sending a sign-in email code, regenerating recovery codes or adding a passkey, sending a partner request, saving your profile, saving or requesting a booking change, settling a group booking, and the family-group forms. It only does this if focus fell to the page, so an error message that takes focus keeps it.
