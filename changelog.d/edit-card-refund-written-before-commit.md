- **A card refund from a booking edit is no longer lost if the server restarts at the wrong moment** (#4992). Shortening a stay, removing a guest, a batch edit that lowers the price, or a guest's acceptance that re-prices a booking down used to save the edit first and record the card refund as owed only if Stripe then refused or failed. A restart between the two left the lower price with no refund and nothing in **Refunds owed**. The edit now records the refund as owed in the same save, with the exact slices it will ask Stripe for, then makes the refund and marks it done. If the server stops in between, the payment recovery job finishes the same refund under the same Stripe request, so it is made once. What Stripe is sent, and what the member's email says, are unchanged.
