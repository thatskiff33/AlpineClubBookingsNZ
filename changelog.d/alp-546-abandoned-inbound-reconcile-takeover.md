- **Fixed:** an inbound Xero webhook reconcile whose server stopped mid-run no longer leaves its operation stuck under the dead run's claim. Replaying that event takes the operation over under a fresh claim, and a late result from the dead run can no longer land on it. A crashed event is not retried by itself, so it waits for a Replay. Outbound Xero operations are unchanged (`INV-INT-038`).
