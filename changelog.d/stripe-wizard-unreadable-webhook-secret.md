- **Stripe setup no longer gets stuck after the app's auth secret changes.** When only the stored webhook signing secret could no longer be read, **Admin → Stripe → Setup** kept warning on **Enter keys** and kept **Continue** disabled even after both keys were re-entered, so the **Webhook** step, the only place to replace that secret, could not be reached. Each step now warns about and waits on only the credential it asks for: **Enter keys** for the secret and publishable keys, and **Webhook** for the signing secret, which now says it needs pasting again. The connected-account check also runs when only the signing secret is unreadable.
