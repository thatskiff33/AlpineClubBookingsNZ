- **More member screens name their own browser tab, and the application confirmation is a heading (#5217).**
  Profile, Book a stay, Lodge induction, Report a maintenance issue, Forgot your password, the two sign-in security steps and the guest chore sheet each now show their own title in the browser tab, followed by the club's name. Before, they all showed the club's default title, so a member with several tabs open could not tell them apart and a screen reader announced the same title for each. A title is fixed text: it never shows a name, an amount or a link's private code.

  On the membership application page, "Application submitted" is now a heading, so someone using a screen reader who has just applied can jump straight to it. Nothing looks different on screen.
