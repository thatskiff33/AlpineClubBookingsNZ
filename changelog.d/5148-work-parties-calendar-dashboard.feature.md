- **Work parties go on the Events Calendar by themselves** (fork #118). With the
  Events calendar module on, creating a work party adds one all-day entry for
  each of its nights, titled "Work party: {name}", with the lodge as location.
  Editing it moves the entries with it, deactivating hides them and activating
  shows them again, and deleting it removes them. The entries are read-only on
  the calendar, with a link to the work party. Work parties made before this
  have an **Add to calendar** button, so a club that typed one in by hand does
  not get it twice.
- **Members see upcoming work parties on their dashboard and can join one in a
  click.** A new **Work Parties** card lists up to five upcoming active work
  parties, each opening a work party page with its nights, lodge, discount and
  description. **Join Work Party** opens Book a Stay with the nights, the lodge
  and "I am attending a working bee" filled in; the member adds guests and pays
  as usual, and every booking rule still applies. Only members see the card,
  the page and the button — not organisation accounts or non-member logins.
