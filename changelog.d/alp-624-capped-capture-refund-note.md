- **A refund of a late card payment that Xero recorded only in part is now credited back only for that part (#4383).**
  When a late card payment for a booking change is recorded against an invoice with less room than the payment, Xero takes only part of it and an officer is emailed about the rest. If that payment was then refunded, the app used to raise a refund credit note for the whole refund, leaving Xero's Stripe account below the bank. The note now stops at the part Xero recorded. The rest of the refund appears on the Xero repair tool's record-by-hand finding, to record by hand only if an officer recorded the rest of the payment by hand as the alert asked. The officer's alert is unchanged, and refund notes already raised are not touched; one raised earlier for the whole refund may now appear in the Xero reconciliation report as refund coverage above the refunded total, which `docs/MAINTENANCE.md` explains how to settle. Such an earlier note is never read as a card refund that failed later, so closing a failed refund as "Paid another way" queues no Stripe reversal for it and the inbound recount takes nothing off for it. Where a Stripe reversal from an older close already undid such a note, it is not discounted a second time, so a later refund that fails is still reversed in full; a close made since this change reverses only the part Xero recorded, so the rest stays for the officer to reverse by hand and the app never reverses it again.
