- **The nightly backup now refuses a dump it could not restore (#5193).**
  When the server's `pg_dump` is a newer PostgreSQL version than the database it backs up, its dump is not guaranteed to load back into that database (PostgreSQL 17's `pg_dump` writes a setting PostgreSQL 16 rejects). The backup now fails with a message naming both versions and keeps no file, so the problem shows as a failed backup instead of a restore that breaks when you need it. Install the client tools matching your database server; the application's Docker image already includes them. CI now runs on Ubuntu 26.04, and its real-database checks take their PostgreSQL client tools from the database container's own image.
