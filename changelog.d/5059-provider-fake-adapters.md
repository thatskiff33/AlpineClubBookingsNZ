- **Tests now run the app's real Xero and Stripe code against the in-memory provider fakes** (#4908). Test-only transports serve the app's own Xero and Stripe clients from `XeroFake` and `StripeFake`, so the booking-invoice push, the inbound invoice reconciliation and the Stripe webhook handlers can be tested unmocked. Two new real-database tests use them: one pushes a booking invoice and settles it from a part payment and then the rest, and one records a dashboard refund, its redelivery and a later `refund.failed`. The transports can be switched on only inside tests, and a census fails if production code imports any test code. The provider contract fixtures can now be marked `recorded-sandbox` with their capture date and API versions, and `docs/TESTING.md` sets out how the owner captures and sanitises them. Nothing changes for members or operators.
