- **An emailed link, Google, or a recovery code no longer counts as confirming
  who you are (#4994).** The five-minute confirmation clock now starts only
  when someone signs in with a password, or with an authenticator-app code.
  Signing in from an emailed link or with Google, or finishing with a recovery
  code or an emailed code, leaves it unset, so the first protected action
  asks for a password. Nothing asks for that confirmation yet.
