- **The Xero Account Mappings section no longer keeps reloading when its load fails (#5203).** On the Xero setup screen, opening **Account Mappings** when the mappings could not be read used to request them again and again, so the error flickered in and out. The section now tries once each time it is opened; a failure stays shown until the admin presses **Refresh Xero reference data**, closes and reopens the section, or reconnects Xero. The contact-group list on the same screen already behaved this way and now shares the same rule.
