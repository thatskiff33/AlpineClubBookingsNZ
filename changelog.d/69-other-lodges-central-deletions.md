- **A lodge deleted on the Alpine Central Server is now removed here too ([triyder/AlpineClubBookingsNZ#58](https://github.com/triyder/AlpineClubBookingsNZ/issues/58)).** The central server now tells every club which lodges it deleted (server **API 2.4**), however long since the club last downloaded. On the next download the lodge disappears from the Other lodges list and the booking-request form, unless a booking or booking request here still refers to it: then it is kept, marked **Not found on the Alpine Central Server** with its counts, and named in the **Download** message. A lodge marked **Not found** that nothing refers to (for example a duplicate left by an earlier rename) now has a **Remove** button, for an administrator with lodge edit rights, after a confirmation; every removal is audited. Lodges the central server still lists cannot be removed here. This site and the central server must both be on 2.4; syncing pauses while they differ. No database change on this site.
