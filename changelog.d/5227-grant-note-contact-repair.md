- **A manual credit grant's Xero credit note no longer sticks in the queue after a contact repair (#5221).** When a member's Xero contact was stale, the app repaired it and tried again, but the retry stored the note without the details the Xero queue uses to recognise it. If that retry also failed, the note went back to the queue and was skipped on every pass, so the credit never got its Xero note and spending it kept waiting. The repaired request now keeps those details, built by the same code that queues the note at approval. A note that is already stuck is not released by this change: the pull request lists the database check that finds one and how to release it.
