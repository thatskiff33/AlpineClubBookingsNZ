## Who

owner

## What to do

Once, after the deploy, run `pnpm run xero:revived-refund-note-report --list`.
If it stops part way, resume it later with `--resume-from <id>`. Go through what
it lists with the treasurer. `docs/UPGRADING.md`, "Find refund notes Xero voided
that the app still counts (#4336)", has the detail.

## How to check it worked

The run reached the end, and the treasurer has agreed what to do about each note
it listed.
