- **Chores, Lockers and Lodges: a failed action now takes you to its explanation.** When saving, deleting, deactivating or bulk-creating on these admin pages failed, the message used to appear in a plain box elsewhere on the page and nothing moved, so a keyboard or screen-reader user stayed on the button with no sign it had failed. The failure now appears in an announced alert that takes focus, and takes it again if the same failure repeats. A failed list load still shows quietly where the list would be, and no longer hides the lodge list after a failed deactivation. Saving a chore or a lodge edit, which closes the form, now brings you back to the top of the page.
