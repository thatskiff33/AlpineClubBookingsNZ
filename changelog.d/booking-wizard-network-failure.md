- **The booking wizard no longer freezes when the connection drops.** On **Book a Stay**, a lost connection or a server error page used to leave **Continue**, **Continue to Payment** (or **Confirm Booking** / **Submit for Review**), **Join Waitlist** or **Save as Draft** greyed out on its busy label with no message, and the only way out was to reload and re-enter everything. Each button now comes back and the wizard says what happened. For a booking, waitlist place or draft it says the outcome could not be confirmed and asks the member to check **My Bookings** before trying again, because the server may already have made it (and used any account credit applied). A failed price check simply asks them to try again. Refusals the server explains, such as a full lodge or a member already booked on those nights, read exactly as before.
