- **The last admin screens now say why a request was refused, even when the server's answer is an error page.** The booking-desk price quote, chores, lockers, a member's lodge access, age-tier settings, mountain conditions and work parties used to show "Unexpected token < in JSON" (or, for age tiers, "Network error") when a refusal came back as a web-server error page. Each now shows the server's own reason when it gives one, and otherwise its own plain sentence such as "Failed to save work party event". A work party's attending bookings that cannot be loaded now say so instead of showing "Loading bookings..." indefinitely, and a work-party activate or deactivate that gets an error page or no answer at all is reported instead of failing silently.
