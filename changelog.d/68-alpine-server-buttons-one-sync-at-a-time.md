- **The Alpine Central Server Upload and Download buttons no longer run alongside another sync ([triyder/AlpineClubBookingsNZ#66](https://github.com/triyder/AlpineClubBookingsNZ/issues/66)).** The nightly sync already held a claim so that only one sync runs at a time, across every copy of the site; the buttons now take the same claim. Pressing one while another sync is running (the nightly job, or a press in another window) sends nothing and says "Another sync with the Alpine Central Server is running … Try again in a minute", shown as a notice rather than an error. If a sync was cut off part-way by a restart, the buttons may say so for up to 15 minutes, until the claim is released. No database change.
