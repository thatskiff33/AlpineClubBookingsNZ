- **A refund credit note Xero has made is no longer recorded twice, or lost to a busy payment.** The app now checks that no other Xero job already records the note while it holds the payment, so two jobs answered with the same note can no longer both claim it. It also waits up to 30 seconds for a payment another job is holding, instead of 5; if even that runs out, the job is left running rather than marked failed, and officers get one alert naming the note so they can record it by hand instead of raising another.
