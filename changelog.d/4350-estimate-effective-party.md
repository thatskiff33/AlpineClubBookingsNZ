- **A change request's price estimate now counts the whole party you are
  proposing (#4203).** On a stay already under way, the **Admin Request** card
  shows an estimate for the guests it adds. When working out whether the party
  is large enough for the club's group discount, that estimate counted only the
  guests already on the booking and the card's own guests. It left out guests you
  had added or removed in the main editor in the same request, so the estimate
  could show a discount the approval would not give, or miss one it would. It now
  counts the party the request would leave on each night. It still prices only
  the card's guests, and it never looks up or shows a member guest's rate.
