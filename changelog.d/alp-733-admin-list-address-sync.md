- **Admin lists no longer reload their own address when they open, and Members keeps the page a link names (#5295).**
  Payments, Subscriptions, Refund Requests, Member Applications, Membership Cancellations, the Audit Log and the three booking-request queues kept their filters and page in the address by replacing it on every render, even when it was already right. Each of those replaces briefly dropped the page title, so a screen reader could announce no page name. They now share one check with Members and replace the address only when it changes. Members also no longer jumps from the page a link names (such as `?page=3`) back to page 1 a moment after opening; typing a new search still returns to page 1.
