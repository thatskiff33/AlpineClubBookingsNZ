- **Members can now share a message board post with every other club (epic
  #2992).** Tick **Share with all clubs** under the composer and the post is
  sent to the central server and distributed to the other clubs on it. Leave it
  unticked — the default — and the post stays inside your own club exactly as
  before.

  The tickbox only appears usable when your club actually has a central-server
  connection set up. Without one it stays switched off and says so, rather than
  looking as though it worked.

  **Sharing never delays your post.** It goes onto your own club's board
  straight away; reaching the central server is a separate step, and if that
  server is busy or down the post is carried across automatically a little
  later. A post can only ever be published once, however many times that is
  retried.

  **Removing a shared post removes it everywhere.** When an administrator
  removes a post that had been shared, it is withdrawn from the central server
  as well, so it comes off the other clubs' boards too.

- **The message board composer is now a proper editor.** Headings, bold,
  italic, underline, text colour and size, all four alignments, lists, and
  pictures. Pictures are stored on the club's own server and are only visible
  to signed-in members; location data in a photograph is removed when it is
  uploaded, so posting a picture does not publish where it was taken.
