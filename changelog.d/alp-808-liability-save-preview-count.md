- **Saving the subscription liability rule straight after its preview appears reports the right count (ALP-808).**
  Every admin settings section reads its Save action through a shared helper, which picked up each new screen's version of that action only after the browser's next task. A Save pressed in between ran the previous version, so the liability rule's confirmation could say "The preview listed 0" when the preview had listed records. The helper now picks up the new version as each screen is drawn. This also fixes an intermittent CI failure in the liability rule's tests, which now press Save the moment the preview shows, with both an immediate and a slow server reply.
