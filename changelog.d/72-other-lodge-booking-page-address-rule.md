- **An Other lodge's booking page address is now held to the Alpine Central Server's stricter rule ([triyder/AlpineClubBookingsNZ#55](https://github.com/triyder/AlpineClubBookingsNZ/issues/55)).** On **Admin → Lodges → Other lodges**, the **Non-member booking page URL** must start with `http://` or `https://` as typed and may not contain spaces, backslashes, or a user name and password (such as `https://club.nz@other.site`, which reads like the club's site but goes elsewhere). The form says so at **Save**, instead of the nightly upload failing later. An address saved before this rule is flagged as soon as the form opens and must be corrected before the lodge can be saved again; until then the list shows it as plain text rather than a link, and the upload leaves it out, so the central server keeps the address it had while the rest of the lodge still uploads. Other addresses on this site (the club's own website and social links) are unchanged.
