- **A pull request that only changes wording or constants no longer has to fill in the locking declaration (#5038).** The automated check on a pull request's description used to demand a full locking declaration for any file whose name mentioned bookings, payments, credits, memberships or Xero, even a file of message wording that cannot take part in a race. It now reads the file as well: the declaration is still required for anything that writes to the database, opens a transaction, takes a lock, runs SQL or imports code that could, and for every schema change, but not for a file that plainly does none of these. When the check cannot read a file, or the file was deleted or renamed, it still asks for the declaration. Nothing changes for people using the booking system.
