- **Officer queues now show every request, oldest waiting first (#4960).** Member applications, refund appeals, booking approvals, change requests, public requests, policy exceptions and the membership cancellation and archive queues each showed only the newest 25 rows, usually with no total and no way to reach the rest, so the requests that had waited longest were the ones out of sight. Each list now shows a total line such as "Showing 1–25 of 40", with **Previous** and **Next** buttons when there is more than one page. The waiting filter of each queue lists the oldest request first; decided and **All** filters still list the newest first. Changing the filter returns to page 1, the page is kept in the address (except on the policy exceptions tab, whose filter is not in the address either) so a reload or a shared link opens the same page, and a link to one booking or request (from an email or **Needs Attention**) shows that record pinned above the list when it is on another page. What approving or rejecting does, and who can see each queue, is unchanged.
