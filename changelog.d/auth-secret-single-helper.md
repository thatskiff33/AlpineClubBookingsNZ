- **One shared check for the app's auth secret when signing links.** Booking calendar links, Google account linking, lobby display pairing, and the member merge, application mapping and seasonal membership preview tokens now all use the same `requireAuthSecret` helper to refuse to sign when `AUTH_SECRET` (or the older `NEXTAUTH_SECRET`) is missing, with the same error messages as before. The preview tokens keep their fixed local key outside production. A new test stops further private copies being added (#4638).
