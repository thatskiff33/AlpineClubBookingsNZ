- **A lodge renamed on the Alpine Central Server is now renamed here, not duplicated, and your own lodge can be renamed here ([triyder/AlpineClubBookingsNZ#64](https://github.com/triyder/AlpineClubBookingsNZ/issues/64)).** Other lodges are matched by the central server's permanent lodge id instead of by name. A rename there renames the same row here, so the lodge's bookings and booking requests stay attached and the booking-request form no longer offers two names for one lodge. Your own lodge's **Name** can be edited in the Other lodges popup once it has been downloaded; the upload sends it with the id (central server **API 2.3**), so the server renames its lodge and every other club follows on their next download. A download never changes your own lodge's name. If a new name is already used by another lodge here, everything else is applied, the old name is kept, and the **Download** message says so. The first download after upgrading fetches the whole registry once to match every lodge; a lodge still unmatched after that is marked **Not on the Alpine Central Server** in the panel, with how many bookings and requests refer to it. Nothing is removed automatically. This site and the central server must both be on 2.3; syncing pauses while they differ. The database change only adds a column and needs no maintenance window.
