- **The Xero API Budget, health and mismatch panels no longer keep reloading when their data cannot be loaded (#5276).** On the Xero admin screen, the Xero API Budget panel, the health snapshot and the Contact Group and Contact Link Mismatches lists used to request their data again and again when the read failed, so the error flickered in and out. Each now tries once each time the admin opens it; a failure stays shown until the admin presses that panel's refresh button, closes and reopens it, or reconnects Xero.
