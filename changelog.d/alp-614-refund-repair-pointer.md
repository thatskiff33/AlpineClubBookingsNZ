- **A refund credit-note retry no longer leaves the payment linked to a note Xero voided (#4279).**
  When Xero created a refund credit note but a follow-up step such as the refund payment failed, pressing Retry repairs it. If the treasurer voided that note in Xero while the retry was running, and the retry was then reset as stuck, the payment could be left showing the voided note as its refund credit note until the job was finished or resolved by hand. The retry now links the note to the payment only when it finishes and still holds the job, and only if the note is still live, so a voided note is never linked back. No money moves differently: balances and refund totals already ignored voided notes. A link already left this way is not changed by this release.
