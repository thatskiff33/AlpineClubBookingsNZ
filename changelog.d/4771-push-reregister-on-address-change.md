- **A booking site whose own address changes now tells the Alpine Central Server.** The site stores the push address it registered beside the push secret, and the 3-hourly pass registers again when `NEXTAUTH_URL` gives a different one. Before, a stored secret was taken to mean "registered" for good, so a site that moved (for example from `new.club.example.nz` to `club.example.nz`) left the server pushing posts to, and asking free beds of, a name that no longer answered, and the central lodge search showed the club as not answering. Sites that registered before this change register once more on their next pass; the server keeps the same secret for an unchanged address. A non-`https://` address still never replaces a working registration. A staging or restored copy must not keep production's Alpine Central Server key: on its own address it would now take the registration over.
