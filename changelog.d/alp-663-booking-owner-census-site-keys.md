- **The booking-owner census no longer fails on edits that never touch a reviewed site (#5232).**
  `booking-owner-census.test.ts` now keys each reviewed ownership comparison, optional owner read, member-keyed helper and unrooted `organisation` selection by its file and its own source line, rather than by line number. Adding or removing lines elsewhere in a file no longer needs a re-measure, and two pull requests that shift lines in the same file no longer conflict in the census. A new unreviewed site, or a reviewed one whose code is gone, still fails by name. Test-only; no behaviour changes.
