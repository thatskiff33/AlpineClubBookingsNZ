- **Connecting to the Alpine Central Server is one step.** Saving the API key on **Integrations → Alpine Central Server** now registers this site's address with the server at once and says how it went (registered, not `https://` so poll-only, waiting for the server's approval, or not reachable), then downloads the club's lodges and opens a **Link your lodges** dialog with the current links (or, for one lodge and one listed, that pair) preselected; nothing is linked until **Save links**, as every club links explicitly. Replacing the key, or moving the server address, now also forgets the old connection's push secret, which before kept the site from ever registering with the new connection. A link saved on a lodge's **Central lodge** card now fills its rates from the Fees page straight away. Saving **Edit my Lodge** uploads the lodge straight away and says whether it was sent. The setup page links to **View all lodge details**.
