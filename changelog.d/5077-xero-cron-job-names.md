- **The ten Xero cron runner jobs now have one spelling of their names in the code (#5077).** Each of those jobs (the membership refresh, outbox, inbound reconcile, credit sync and the rest) was named once where it runs and then typed out again in the scheduler's logs and Sentry check-ins, on the admin cron health page and in the Xero health summary. Those copies would have stopped matching the recorded run history the first time a job was renamed, and nothing would have failed. All ten names now live in one small module that every one of those places imports, and a new test fails if anyone types one of them out by hand again. The payments cycle's jobs are named separately and are not part of this change.

  Nothing changes for clubs: the names themselves are unchanged, so existing run history, the cron health page and Sentry monitors carry on exactly as before.
