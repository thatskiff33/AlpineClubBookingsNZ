- **The admin message board now shows sharing problems, and can withdraw a stray copy (#5246).** Very rarely the central server accepts a shared post but this site cannot record that, or a removed post's copy is not confirmed taken down. Until now nothing on screen said so: the server's id for the copy was only in the error log. A **Sharing problems** box at the top of **Admin → Members → Message Board** now lists each such post in plain words, with the central server id and a **Copy** button. **Withdraw the shared copy** takes that copy off other clubs' boards and records the result; if it fails, the screen says to send the id to the central server's administrator. Every attempt is audited, a failed or half-finished one included, with the ids withdrawn and still outstanding. Where no id was recorded, the entry says who to ask and offers **Mark as dealt with** once the send is 15 minutes old. Removing such a post now withdraws its stray copy too. Posts in the list carry a **Sharing problem** or **Not shared with other clubs** badge with the recorded reason. A post is still never sent twice, and members see none of this.
