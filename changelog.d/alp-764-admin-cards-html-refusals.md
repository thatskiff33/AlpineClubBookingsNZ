- **Admin cards explain a refused action in plain words when the server answers with a web page (#5323).** Fifteen admin cards and panels, including the booking request queues, the email, finance mapping and membership cancellation settings, Copy Booking, the non-member contact form and the Xero sync and retry buttons, could show a technical "Unexpected token" message, or crash their error message, when a refusal came back as a web page rather than the app's usual answer (for example a 502 from the server in front of the app during a deploy). A refused change now shows the same "you do not have permission" explanation the other settings cards show, a server error shows the card's own message, and a reason the server words, such as "Two-factor verification required", is still shown as written.
