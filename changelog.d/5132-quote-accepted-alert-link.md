- **The "Quote accepted, ready for approval" email now opens the accepted requests.** Its review link used to open **Booking Requests → Public Requests** on the **Queue** filter, which lists every open request together, so the accepted request could be buried among them or sit beyond the first page. It now opens that tab on the **Accepted** filter. Emails already sent keep the old link and still open the Queue. (ALP-582)
