- **A failed action on the Alpine Central Server setup page now takes focus to its explanation (#5257).** When **Save**, **Save key**, **Enable** or **Disable**, **Upload** or **Download** fails, keyboard and screen-reader focus moves to the message, and pressing the same button again and getting the same refusal announces it again. Before, the failure appeared quietly at the top of the page.

  The message is the server's own reason when it gives one. When the page gets an error page back, or no answer at all, it shows its own sentence (for example "Failed to save API key") rather than the browser's "Failed to fetch". The same applies to the lodge download that follows a key save and to the link dialog's **Save links**. Successes and notices, such as another sync already running or nothing to upload, still appear in place without moving focus.
