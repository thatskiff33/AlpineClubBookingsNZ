- **A booking officer can now apply a member's missed promo code to a stay that
  has already finished (#4533).** When an officer books a stay for a member and
  forgets the member's assigned free night, the member pays full price. Once the
  stay was over there was no way to put that right in the app, and the
  workarounds — a hand-made Xero credit note, or a redemption typed into the
  records — left the free night showing as unused, so it could be claimed again.

  Now the correction goes through the same approve-and-apply step officers
  already use for finished stays. In Edit Booking, choosing a code on a finished
  stay no longer leaves Save doing nothing: the panel says the stay has finished
  and offers **Send as a promo correction request**, which opens the request in
  Booking change requests. An officer can also type the code into **Promo code to
  apply** on any finished-stay request. **Check the figures** shows the
  reduction, and **Approve and apply** applies the code exactly as Edit Booking
  would on a future stay — who it is assigned to and its limits still apply, and
  a code that doesn't apply is refused with the same reason. The free night is
  then counted as used, the booking's price and ledger are corrected, and the
  reduction comes back in full, as account credit by default (with an unapplied
  account-credit note in Xero) or as a refund if the officer chooses. There is
  no change fee. For a promo-only correction the officer can choose not to email
  the member. Approving twice changes nothing a second time.
