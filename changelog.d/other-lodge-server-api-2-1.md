- **Other lodges follow Alpine Central Server API 2.1: bed counts, the walk in, room or dormitory, two new facilities, and one booking link.** On **Admin → Lodges → Other lodges**, your lodge's editor now records its **double beds**, **single beds** and **minutes' walk to the lodge**, whether guests sleep in a **room** or a **dormitory**, and two more facilities, **ski workshop area** and **games room**. The website field is now the **Non-member booking page URL**, and the separate free-text **How to book** field is gone (its stored values are removed with it, because the central server no longer carries it).

  **This site now requires central server version 2.1.** Syncing only runs while the two versions are identical, so after upgrading this site, syncing pauses until the central server is on 2.1 as well; the Alpine Central Server setup page shows both numbers. The database change drops a column and is declared as needing a maintenance window in `docs/BLUE_GREEN_MIGRATION_SAFETY.tsv`.
