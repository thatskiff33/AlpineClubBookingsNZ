- **The check that every booking confirmation and cancellation writes its member-money journal entry now checks each write, not each file (#4928).** The automated census used to pass as long as a file mentioned the journal-posting call somewhere, so a new or changed cancel path that skipped its entry could go unnoticed. It now requires each function that confirms or cancels a booking to make the posting call itself, at least once for every such write it holds, and names the file and line of each write that falls short. It checks by function, not by branch, so a post on a path the write never takes still counts. No runtime behaviour changes.
