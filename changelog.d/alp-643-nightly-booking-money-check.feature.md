- **The app now checks every night that each booking's money records still agree, and shows any problem on Stuck States (ALP-643).**
  Until now this check could only be run by hand on the server. A new background job, **Booking money check**, runs at 05:30 club time and compares each booking's payment figures with its booking ledger. It only reads: it never changes or repairs anything. What it finds appears on Stuck States as **Booking money records disagree**, naming the bookings, and admins who receive payment failure alerts are emailed the first time each problem is found, never again for the same one. Known history the club's owner has not signed off is listed separately as information, not as an emergency. If the check fails or has not run for more than 36 hours, Stuck States says **Money check did not run** instead of showing nothing. Two account credit faults the daily credit check already reported to the error log now also appear on Stuck States: **Members with negative credit** and **Cancelled bookings still holding credit**. Names show only to admins with Membership view, and credit amounts only with Finance view as well.
