- **Clubs can choose their conditions report and booking timings (#4932).**
  The generic ski-field widget and Whakapapa (Mt Ruapehu) report now have separate
  module switches. New installs start with the Whakapapa report off; existing
  commissioned installs retain their choice. Data and finance downloads use the
  club’s short name. Booking Policies → Cancellation lets officers set the
  arrival reminder lead, first extra-payment reminder delay and exception hold
  length from 1–30 days, keeping defaults of 3, 3 and 7. Existing exception
  requests keep their original deadlines.
